# Competitive capability matrix and positioning dashboard

**Baseline v1.0 · cut-off 2026-11-02 · methodology v1.0.** Source dates and confidence are shown per assessment. Evidence IDs in `evidence-register.csv`.

**Status labels:** PV Publicly verified · PtV Partially verified · ANN Announced or planned · NPV Not publicly verified · N/A Not applicable. NPV is **not** a statement that a capability is missing. *(searched)* means a search was run and found nothing. *(not searched)* means this pass did not look for it.

**Moved this month:** not applicable. This is the baseline, so there is no previous assessment to compare against.

**Coverage warning:** this pass focused on AI, ownership, scale and a few core capabilities. Most cells for competitors outside those areas are NPV *(not searched)*. Do not read the empty cells as gaps.
